# Khana Diary

An Indian-food calorie diary that runs entirely on your phone, offline.
Open the app link once, then use "Add to Home Screen" (iPhone: Share → Add to Home Screen; Android: menu → Install app).
Your log, recipes and profile stay on your phone.

**Status:** personal test build. Calorie values are recipe-based estimates built from India's food composition
table (IFCT 2017, NIN-ICMR), the Indian Nutrient Databank (INDB) and USDA FoodData Central, recomputed with
corrections. Not medical advice.
